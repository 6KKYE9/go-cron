# go-cron

零依赖的 cron 表达式解析器与下次触发计算器，纯 Go 标准库实现。

## 用法

```powershell
go run . -e "0 9 * * 1-5"            # 工作日早 9 点，看接下来 5 次
go run . -e "*/15 * * * *" -n 3      # 每 15 分钟，看接下来 3 次
go run . -e "30 8 1 * *" -from "2026-08-06 00:00"
```

## 语法

标准 5 字段：`分 时 日 月 周`

- `*` 任意
- `,` 列举：`1,15,30`
- `-` 范围：`1-5`
- `*/n` 步长：`*/15`（每 15）
- 周字段 `0-6`，`0=周日`
- 日与周字段同时非 `*` 时为「或」关系（符合标准 cron 语义）
