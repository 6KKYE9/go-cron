# go-cron

解析 cron 表达式、算出接下来 / 最近几次的触发时间。标准库实现，没用第三方包。

```powershell
go run . -e "0 9 * * 1-5"            # 工作日早 9 点，看接下来 5 次
go run . -e "*/15 * * * *" -n 3      # 每 15 分钟，看接下来 3 次
go run . -e "30 8 1 * *" -from "2026-08-06 00:00"
go run . -e "0 9 * * *" -tz "America/New_York" -last   # 指定时区并看最近一次触发
```

表达式是标准 5 字段：`分 时 日 月 周`。

- `*` 任意
- `,` 列举：`1,15,30`
- `-` 范围：`1-5`
- `*/n` 步长：`*/15`（每 15）
- 周字段 `0-6`，`0=周日`
- 日与周字段同时非 `*` 时取「或」关系（标准 cron 语义）

额外选项：

- `-tz` 指定时区（如 `Asia/Shanghai`、`America/New_York`），按该时区解析 `-from` 并输出触发时间
- `-last` 同时打印最近一次触发时间（`Prev` 反向计算，与 `Next` 对称）
- `-n` 控制显示接下来几次（默认 5）

测试覆盖了解析、越界校验、步长、工作日和每 15 分钟触发、日周 OR 语义，以及 `Prev/PrevN` 反向计算（含起点恰好命中的边界）。
